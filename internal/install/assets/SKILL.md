---
name: sous
description: Use when the user asks what is waiting on them or where they left off, says "note this", "remind me", "later", "follow up", "file this", or "sous", when work is being put off (a TODO for another day, something to check with a person, an idea for another project), or when the user wants a task handed to an agent to do in the background ("have an agent fix X"). sous is the user's personal list of what is waiting on them across every project; it hands work to agents and tracks it, but never does the work itself.
---

# sous

sous is a command on this machine. Run `sous help` first: it lists every
command and the rules for agents. Every command also answers `--help`, and
sous's own output suggests the next step. Follow the CLI; this skill only
tells you it is there.
